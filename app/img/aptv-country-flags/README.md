# APtv country flag set

Anteprima completa delle bandiere per i codici paese usati dal catalogo APtv.

I file sono SVG 4:3, uno per codice, e non sono ancora collegati al progetto.
Il set comprende 60 asset: tutti i codici paese presenti in `regionNames`, più
`AR` per Arabic e `OTHER` come fallback grafico.

Mappature APtv non ISO:

- `AG` usa la bandiera ISO `AF` (Afghanistan)
- `CG` usa `ME` (Montenegro)
- `MA` usa `MY` (Malaysia)
- `SU` usa `SR` (Suriname)
- `UK` usa `GB` (United Kingdom)

Fonte locale del pacchetto: `flag-icons` 7.5.0.

I codici aggregati o funzionali (`AFR`, `ASIA`, `CR`, `EXYU`, `KU`, `LA`,
`MC`, `RX`, `TS`, `WT`, `4K`, `8K`) restano separati dalle bandiere nazionali
e non vengono forzati dentro questo set.
