# APtv screenshots

This gallery shows the APtv interface at 1920×1080 and is split into its two
main areas:

- **OpenAP / AP** — hotspot, network, DHCP/DNS and system administration;
- **IPTV** — dashboard, movies, recordings and TV-series browsing.

The AP screenshots are sanitized copies prepared for public documentation.
Hostnames, IP addresses, client identifiers, interface identifiers and
operational log details have been redacted. The IPTV screenshots show the
catalog and navigation layout using example content.
