## OpenAP-specific work

OpenAP adds a capability-based universal installer and a focused interface for
AP-over-Ethernet and two-radio repeater deployments. It also adds OpenAP-owned
network helpers, role detection, firewall and DHCP/DNS workflows, responsive
dashboard components, recovery monitoring and product branding.

This summary does not claim authorship of inherited RaspAP code. Git history,
retained source notices and this file document the relationship between the
projects.
