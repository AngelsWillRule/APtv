# OpenAP Code of Conduct

## Our pledge

OpenAP is an open-source community project for understandable and recoverable
wireless networking on Debian-based systems. Contributors and maintainers
pledge to make participation respectful, constructive and free from
harassment.

## Expected behavior

- Treat other participants with respect and patience.
- Give and accept specific, constructive technical feedback.
- Respect differing experience levels, viewpoints and backgrounds.
- Focus discussion on the project and its users.
- Protect private information found in diagnostic or security reports.

Unacceptable behavior includes harassment, personal attacks, trolling,
discriminatory language, threats, deliberate disruption and publishing another
person's private information without permission.

## Enforcement

Maintainers may edit or remove contributions that violate this code and may
temporarily or permanently restrict participation when necessary. Reports
about conduct should use an appropriate private maintainer channel; security
reports must use the process in `SECURITY.md`.

## Scope

This code applies in project spaces and when a person officially represents
OpenAP in public or private community interactions.
